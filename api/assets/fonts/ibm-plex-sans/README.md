# IBM Plex Sans for Special Terms PDFs

Unmodified Regular and SemiBold TrueType fonts from [IBM/plex](https://github.com/IBM/plex/tree/bf260093582f04622aacc1e9f9ca604d7ccd0c42/packages/plex-sans), pinned at `bf260093582f04622aacc1e9f9ca604d7ccd0c42`. Licensed under the bundled SIL Open Font License (license whitespace normalized to LF).

Regular is the PDF body; SemiBold is the PDF heading face (registered as bold). Both are embedded locally with no runtime network or installed-font dependency. The editor uses the existing self-hosted IBM Plex Sans Variable at matching weights 400 and 600.

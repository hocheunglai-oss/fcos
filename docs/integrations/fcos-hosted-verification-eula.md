# FCOS Hosted Verification — internal-use licence

Version 1.0 — 17 October 2026

## Scope

FCOS Hosted Verification is a private integration for the FCOS project administrator and people already authorised by that administrator. It supports internal release verification by reading Vercel project, deployment and integration-configuration metadata for the selected FCOS project.

## Permission to use

Authorised users may install and use this integration only for internal FCOS administration, within their existing access permissions. This permission does not grant access to another project, a public distribution right, ownership of FCOS software or trademarks, or rights under another party's software licence.

## Limits

The integration is configured with read-only Integration Configuration, Deployments and Projects scopes. It does not authorise deployment, environment-variable or domain changes, Production promotion, financial transactions, or access outside the selected project. Those actions remain subject to their separate controls and approvals.

Do not share credentials, bypass project restrictions, expand permissions without authorisation, or use this integration to access another person's data without permission.

## Platforms and availability

Vercel, GitHub and other platforms used by the FCOS release process remain subject to their own terms and access controls. This internal-use licence does not amend those agreements or any existing employment, confidentiality or customer agreement. It creates no subscription fee or service-level commitment.

## Ending access

The project administrator may stop use or remove the integration. Uninstalling or revoking its access prevents future authorised API reads; it does not itself delete historical release evidence already retained by FCOS or its service providers. Requests concerning retained data should be sent to the contact below.

## Privacy and contact

The accompanying FCOS Hosted Verification privacy notice describes the integration's data handling. For access, support or privacy requests, contact the FCOS project administrator at **vincent@cosulich.com.hk**. Do not send credentials in a support request.
